# EternalForge — Awakening

RPG fantasy 3D originale, progettato per iPhone in modalità landscape e desktop.

## Prima build
- Scena 3D WebGL con Three.js
- Controlli touch con joystick virtuale
- Movimento del personaggio e telecamera follow
- Creature ostili, attacco ravvicinato e abilità ad area
- Ricompense in oro e interazione di forgia dimostrativa
- HUD responsive e supporto tastiera desktop

## Avvio con GitHub Pages
1. Repository → Settings → Pages
2. Build and deployment → Deploy from a branch
3. Branch: main, folder: / (root)
4. Save

Il progetto è una prima build giocabile single-player. Il multiplayer richiede in una fase successiva un server autorevole, account e persistenza; non è ancora attivo.

## Stack
- Three.js via CDN
- JavaScript ES modules
- HTML/CSS statici

EternalForge è un'opera originale ispirata a temi generali del fantasy RPG e del crafting. Non utilizza personaggi, asset o storia di opere esistenti.
